# Traceability 与收敛

维护 `合同字段 → 需求 → 规格 → 计划 → 任务 → 代码/文档 → 测试 → Evidence` 矩阵。每个 MUST 必须到达 verified；孤立任务、无测试实现、无来源证据和未关闭 P0/P1 gap 均阻断。Converge 仅报告实际差距，不可用 reconcile 改写合同来掩盖漂移；Evidence 必须带路径、命令/观察、时间、退出码和校验和。
