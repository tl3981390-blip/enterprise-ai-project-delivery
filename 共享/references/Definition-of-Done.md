# Definition of Done（DoD）

> 被所有施工相关模块引用的公共完成定义。对齐第一设计 `11` 与开放标准。

## 一、通用 DoD（任何增量/模块完成必须满足）

- [ ] 目标与合同一致：无目标漂移、无越权、无未经核算的能力扩展
- [ ] 真实执行：关键逻辑有真实运行证据（test_result/api_response/browser_capture，非 model_text）
- [ ] 已测试：对应测试用例真实通过（退出码 0 + 记录）
- [ ] 已提交：增量以可核验 Git 提交落地
- [ ] Evidence：有对应阶段证据入 `evidence/`
- [ ] 无阻塞项：DoD 相关 blocked 项均已消除
- [ ] 无假验收：未用“代码存在/文档说支持/AI 说完成”冒充完成

## 二、关键规则（源自最高原则）

1. **测试文件存在 ≠ 测试通过**：必须真实运行并留存退出码/记录。
2. **代码看起来没问题 ≠ 完成**：需真实行为证据。
3. **README 描述 ≠ 功能支持**：需真实调用/运行证据。
4. **一次增量不得一次性大段施工**：须可增量实现、增量验收（`11`）。
5. **失败不得靠改报告掩盖**：保持真实错误证据，修复后重跑。

## 三、使用方式

- 各模块在自身 Verification/完成判定处引用本 DoD。
- 未达 DoD → 该增量标记未完成 → 不得进入下一阶段。
