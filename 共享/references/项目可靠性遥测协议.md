# 项目可靠性与交付效率遥测协议

遥测对象仅是当前 Skill 管理的 AI 项目交付事件，不是员工行为。每个事件必须带唯一 event_id、稳定 task_id、stage_id、可信 timestamp/timestamp_source、event_type、detected_by、evidence_refs 和 correlation_id。

分类顺序：

1. 用户主动变更记 USER_SCOPE_CHANGE，不能污染 AI_REWORK_EVENT。
2. 网络、第三方服务等记 EXTERNAL_FAILURE；除非 AI 对其处理再次犯错，否则不算返工。
3. 经正式批准的架构变化记 APPROVED_ARCHITECTURE_CHANGE，不算 Drift。
4. AI 错误导致重做才记 AI_REWORK_EVENT。

历史不可修改。发现旧记录有误时追加 CORRECTION_EVENT 并引用 source_event_id。DRIFT_CORRECTED 必须引用先前 DRIFT_DETECTED；AUTO_RECOVERY_SUCCESS 必须引用 FAILURE_EVENT、RECOVERY_ATTEMPT 和新的测试 Evidence。Suspend/Resume/Handoff 必须沿用同一 task_id。

Token 只接收 Provider/Harness 的真实 usage；缺失时 metrics 状态为 NOT_AVAILABLE 且不得输出零值。时间只使用带 SYSTEM_CLOCK 或 PROVIDER 来源的 ISO-8601 时间戳。
