# 公共检查清单（通用 Compliance / 质量清单）

> 被多个模块引用的通用检查项。分结构、触发、质量、安全/合规四类。仅供设计期引用，落地执行见 `05_测试与验收`。

## 一、结构
- [ ] frontmatter 字段集合法（name/description≤1024/license/compatibility/metadata）
- [ ] 引用路径完整（references/scripts 链接均存在）
- [ ] 无空造 scripts/，无重复内容
- [ ] 版本 semver 合法

## 二、触发
- [ ] should-trigger 命中
- [ ] should-not-trigger 不命中
- [ ] 边界/near-miss 判定正确

## 三、质量（DoD 挂钩）
- [ ] 关键逻辑真实测试通过
- [ ] 有真实行为证据
- [ ] 增量可验收

## 四、安全 / 合规
- [ ] 权限按 READ/WRITE/DELETE/EXECUTE/ADMIN/EXTERNAL 最小化
- [ ] 无生产库/root/外发自动执行
- [ ] 敏感数据脱敏（redact_secrets）
- [ ] 来源/license 合规（NOTICE）
- [ ] 外部系统访问经企业批准 + 正式接口
